# Guessing-Number-Game
Guessing Number Game — a web game (Node/Express backend, HTML/CSS/JS frontend) where players guess a secret number in a chosen range. Guesses allowed = log₂(range), one less than perfect binary search needs. Hints narrow the range each turn. Ported from C++; secret stays server-side.UI redesign adds neon glassmorphism theme, animations, and emotes.
